# Photos des témoignages

Pour chaque commerçant, **1 à 4 photos** : elles forment une pile de tirages
que le visiteur feuillette sur l'accueil (la première est sur le dessus).
Idéal : le présentoir reviu au comptoir, l'établissement, l'équipe.

- Format : WebP ou JPG, cadrage **vertical 4/5** (ex. 1000 × 1250 px), < 400 Ko.
- Noms de fichiers simples, sans espace ni accent : `boulangerie-martin-1.webp`.

Puis ajouter l'entrée dans `src/lib/testimonials.ts` (champ `photos`). La
section « Ils l'ont installé » apparaît automatiquement dès le premier
témoignage.
