# Photos des témoignages

Une photo par commerçant, montrant le présentoir reviu installé dans
l'établissement (comptoir, accueil, caisse).

- Format : WebP ou JPG, cadrage **vertical 4/5** (ex. 1000 × 1250 px), < 400 Ko.
- Nom de fichier simple, sans espace ni accent : `boulangerie-martin.webp`.

Puis ajouter l'entrée correspondante dans `src/lib/testimonials.ts`
(`photo: "/temoignages/boulangerie-martin.webp"`). La section « Ils l'ont
installé » apparaît automatiquement sur l'accueil dès le premier témoignage.
